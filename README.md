# Strategic Wrestler
https://cannonfodderrr.github.io/Strategic-Wrestler/

Wrestling Analytic and Manager App

Create Season (Folkstyle, Freestyle, Greco)

Load Roster (Boys, Girls, Varsity, JV, Junior High, Elementary, College)

Load Duals and Tournaments with Opponents

Upload Match Video from Computer or Youtube

Manually Score Match

AI Analyze Match (INW)

Import Live Scoring from a Companion App - MatSide

Custom Stats

Develop AI Training Plans

Create and Assign Awards

Track Gear Issue and Attendance 

Print Schedule, Bout Sheets, Rosters
